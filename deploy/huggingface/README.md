# AgroSmart API

Django REST backend for [AgroSmart](https://github.com/gloriaglory/Agrosmart):
crop recommendations, leaf disease detection, market prices, marketplace,
education and the farming assistant. The website runs on Vercel and calls this API.

Built from `deploy/huggingface/Dockerfile` in the GitHub repository.
